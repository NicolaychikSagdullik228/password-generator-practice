# 📘 Генератор паролей + БД сохранённых
**Автор:** Левицкий Егор | **Группа:** ИС-31 | **Вариант №:** 3

## 📌 Описание
Консольное приложение для криптографически стойкой генерации паролей и их безопасного локального хранения. Программа позволяет создавать пароли заданной длины, автоматически оценивает их надежность и сохраняет в базу данных SQLite под защитой единого Мастер-пароля. Реализован экспорт базы в формат CSV, совместимый с менеджерами паролей KeePass/KeePassXC.

## 🛠 Технологии
- Python 3.10+
- Встроенные модули: `secrets`, `sqlite3`, `hashlib`, `csv`
- Библиотеки: см. `requirements.txt`
- Тесты: `pytest`
- Контроль версий: Git
